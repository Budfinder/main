      How it works & price history table

      The benchmark averages the same 20 shops, giving each shop equal weight. Within each shop, each strain contributes its average price per gram once. The location views average across strains in the full database. Repeat checks do not add extra weight. For a personal benchmark, strain totals count each shop’s strains separately.

      Markers are recorded observations. The continuous line joins those points; prices between markers are unknown. Dates show when Budfinder recorded listings, rather than when shops published menus. Last known listings are carried forward until a replacement or removal is recorded. Earlier coverage is incomplete and edits without historical records cannot be reconstructed. The latest snapshot uses the current database.
