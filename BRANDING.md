# Budfinder brand assets

The redesigned brand mark is configured once in `styles/budfinder-polish.css`:

```css
--budfinder-brand-mark-image: url("../images/budfinder-badge-v3.png");
```

The transparent 1024 × 1024 master is `images/budfinder-badge-v3.png`. The
multi-resolution browser icon is `images/budfinder-badge-v3.ico`. The earlier
`images/budfinder-mark-v2.png` redesign and original `images/IMG_5124.ico`
remain available as rollbacks.

The mark combines:

- The established circular badge and map routes from Budfinder's GitHub identity.
- A central location-pin silhouette for discovery.
- A simplified botanical motif for product relevance.
- Bold, flat geometry that remains legible from 16px through large-format use.
- Budfinder's deep forest, leaf green, gold, and warm off-white palette.

Remaining optional brand work:

- Refresh `static/images/budfinder-social.png` for link previews.
- Consider a custom wordmark only if the existing text lockup needs to become artwork.
